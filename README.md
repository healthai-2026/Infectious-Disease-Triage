# Infectious-Disease-Triage

AI-Enabled Clinical Triage and Remote Monitoring for Infectious Disease Care.

## Project Structure
- `docs/`: Project documentation and guidelines.
- `README.md`: Project description.

## Planned Features
- Cohort definition & ICU clinical extraction pipeline.
- Baseline ML and deep learning sequence models (Logistic Regression, XGBoost, LSTM, Transformers).
- Advanced clinical NLP and multimodal fusion.
- Deployment metrics and explainability (SHAP, attention maps).
